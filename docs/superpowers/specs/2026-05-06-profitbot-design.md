# ProfitBot Design — Autonomous Digital Product Launch Agent

**Date:** 2026-05-06  
**Spec source:** `gumroad-agent-spec-v2.md`  
**14-day window:** 2026-05-06 → 2026-05-20

---

## Overview

An autonomous Python agent that validates a niche, creates a digital prompt-pack product, launches it on Gumroad, builds an email funnel via ConvertKit, distributes across 5+ channels, and monitors/adapts daily over 14 days. Target: >$100 net revenue and 25+ email subscribers by Day 14.

---

## Architecture

### Approach: Scheduler-based independent phase scripts

Each phase is an independent, idempotent script. `agent.py --full-run` calls them in sequence. A cron job handles daily monitoring. `state.json` tracks completed phases so any script can be safely re-run after a crash or manual intervention.

Any step requiring human action (email verification, CAPTCHA, phone verification) is written to `manual_work.md` and the script exits cleanly. The user resolves the item and re-runs the script.

## Phase 0: Validation

**Goal:** Determine the best niche before building anything.

- Scrape Gumroad bestsellers via `requests` + `BeautifulSoup` (public pages, no auth)
- Query Reddit JSON API (`reddit.com/r/{sub}/search.json`) for demand signals across niches: generic sales, recruiter outreach, real estate, B2B SaaS, agency outbound, freelancer pitching
- Call Claude API to compare niches and generate `validation_report.md` with: recommended niche, optimal price point, top 3 messaging angles
- Fallback: if scraping returns insufficient data, default to "Recruiter Cold Outreach Prompts"
- Outputs: `validation/gumroad_competitors.csv`, `validation/reddit_demand.csv`, `validation/validation_report.md`

**Blocks all subsequent phases.**

## Phase 1: Product Creation

**Goal:** Generate two PDF products tuned to the validated niche.

- Call `claude-sonnet-4-6` to generate 50 prompts (5 categories × 10 each) + 5 follow-up email sequences
- Generate cover image with `Pillow` (text + gradient, no external service)
- Render PDFs with `reportlab`: `free-sample-pack.pdf` (10 prompts) and `full-prompt-pack.pdf` (50 prompts + sequences)
- Save persona (name, bio, backstory) generated by Claude to `state.json` for cross-platform consistency
- Generate `compliance_notes.txt` (static legal/tax reminders per spec)

---

## Phase 2: Email Infrastructure (ConvertKit)

**Goal:** Build an email capture funnel with automated 5-email drip sequence.

- Playwright automates ConvertKit signup with `jeffcrooks.ai@gmail.com`
- Email verification → logged to `manual_work.md`, script exits
- On re-run after verification: create landing page, upload free PDF, configure 5-email sequence (Days 0, 1, 3, 5, 7)
- Save landing page URL to `landing_url.txt`
- Set up `SUBSCRIBER30` code for Day 10 email blast

---

## Phase 3: Gumroad Setup

**Goal:** Create the paid product listing.

- Playwright automates Gumroad account creation with `jeffcrooks.ai@gmail.com`
- Email verification → `manual_work.md`, exit
- On re-run: create product listing with niche-tuned copy from `validation_report.md`, upload `full-prompt-pack.pdf`, set price from validation report, add free sample teaser line with `landing_url.txt`
- Create discount codes: `LAUNCH20` (20% off, 30 days) and `SUBSCRIBER30` (30% off)
- Save Gumroad product URL to `state.json`

---

## Phase 4: Multi-Channel Distribution

**Goal:** Drive traffic to the ConvertKit landing page across 5 channels.

**Persona:** Fully synthetic (name, bio, backstory) generated by Claude in Phase 1, stored in `state.json`.

**Channel posting schedule** (driven by `(today - start_date).days`):

| Day | Action |
|-----|--------|
| 1-3 | Reddit warm-up posts (value, no links) |
| 1-3 | X warm-up engagement (replies to niche accounts) |
| 3   | Indie Hackers launch story post |
| 4+  | Reddit value posts → landing page |
| 4   | X thread: 5-7 free prompts → landing page |
| 7+  | Product Hunt (if email list ≥ 10 and social proof exists) |
| 7+  | Reddit reposts with variations every 3-4 days |

`distribute.py` checks `logs/channel_log.csv` to avoid duplicate posts. Designed to be re-run daily (cron or manual).

All account creation: Playwright with `jeffcrooks.ai@gmail.com`. Any verification wall → `manual_work.md`.

---

## Phase 5: Monitoring & Adaptation

**Goal:** Daily metrics collection and data-driven decision making.

- Cron job installed by `agent.py --full-run`: `python distribute.py && python monitor.py` at 09:00 daily
- Metrics collected: Gumroad (visitors, sales, revenue, conversion rate), ConvertKit (signups, open rate, click rate), per-channel post performance
- Decision tree fires on Days 3, 7, 10, 14 based on `(today - start_date).days`
- All decisions logged to `logs/decisions_log.txt`
- Day 14: full retrospective + `next_product_recommendations.md`

## Cross-Cutting Concerns

### Resumability
`state.json` tracks: `start_date`, `phase_completed` (0-5 flags), `persona`, `niche`, `price`, `gumroad_url`, `landing_url`, `last_distribute_date`.

### Human Intervention
`manual_work.md` format:
```
## [YYYY-MM-DD HH:MM] Item N: <title>
**Action required:** <exact steps for user>
**Re-run:** `python <script>.py`
**Status:** PENDING
```

### Browser Automation
- `random.uniform(2, 6)` seconds between actions
- `random.uniform(30, 90)` seconds between posts
- CAPTCHA detected → write to `manual_work.md`, raise `ManualInterventionRequired`

### Budget Gates
- `$30` Canva budget: only if Day 3 conversion rate < 0.5% (decision tree)
- `$70` ad budget: only if Day 7 sales = 0 (decision tree)
- All spend logged to `logs/spend_log.csv`

### Email
- `jeffcrooks.ai@gmail.com` used for all account signups
- ConvertKit handles unsubscribe links and physical address (compliant by default)
